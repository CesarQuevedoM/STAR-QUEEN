STARQUEEN — Autonomous AI Task Operator 👑
Executive Summary: A local Python-based LLM integration designed to automate unstructured data processing and execute deterministic workflows asynchronously.

Core Architecture:

LLM Orchestration: Integrates with local environments via VS Code and external APIs (Gemini 1.5 Pro / Anthropic) for complex reasoning tasks.

Secure Deployment: Environment-isolated API key management (.env) for enterprise-grade security and secret scanning compliance.

Data Sanitization: Transforms raw text and messy inputs into strict JSON/Markdown structured outputs for downstream consumption.
